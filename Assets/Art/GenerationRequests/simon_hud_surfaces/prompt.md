# Simon HUD surfaces

Genera un kit modular de superficies 2D transparentes para el HUD de Simon de "A tu Ritmo", usando el mockup maestro aprobado como referencia.

## Entrega

- superficie horizontal redondeada para el HUD superior;
- superficie secundaria para grupos de informacion si es necesaria;
- marco de barra de tiempo;
- marco o superficie para el reloj analogico circular;
- corazones de vida funcionales en estado lleno y vacio, sin decoracion adicional;
- pequenos marcadores de progreso redondos para la guia de compas.

## Restricciones

- Fondo transparente.
- No incluir palabras, numeros, letras, logotipos ni marcas de agua.
- El reloj debe ser una esfera analogica simple, con manecillas claras; no reloj de arena.
- Los corazones solo representan vidas y deben ser legibles en tres estados: lleno, vacio y deshabilitado.
- Estilo redondeado, crema, azul petroleo, turquesa y acentos moderados.
- Piezas separables y aptas para Sprite Mode y 9-slice.
- No incluir fondo, tablero, botones de jugar/repetir ni una composicion de pantalla completa.

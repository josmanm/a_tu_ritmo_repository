# Mockup A: refinamiento conservador de SimonScene

Genera un mockup de pantalla completa para un videojuego educativo infantil de ritmo y memoria musical llamado "A tu Ritmo". Usa como referencia principal la captura actual adjunta de `Assets/Scenes/SimonScene.unity` y, si se adjuntan, las referencias de esta carpeta.

## Objetivo

Mejorar la claridad y la consistencia visual de la pantalla Simon sin cambiar su funcionalidad ni su composición general. Debe seguir siendo reconocible como un tablero de memoria musical con cuatro zonas de color, HUD superior, puntuacion, vidas, tiempo, boton de menu y feedback central.

## Direccion visual

Refinamiento conservador: estilo infantil amable, musical, limpio y accesible. Formas redondeadas, volumen suave, sombras discretas, bordes claros y acabado 2D ilustrado consistente. Evita realismo, texturas ruidosas, brillos agresivos, perspectiva extrema y decoracion que compita con el tablero.

## Composicion obligatoria

- Mantener un tablero Simon central grande como foco principal.
- Mantener cuatro zonas de juego diferenciadas por color y con suficiente separacion.
- Mantener HUD superior con puntos, tres vidas, barra de tiempo y boton de menu.
- Mantener feedback central temporal para estados observar, tu turno, correcto e incorrecto.
- Mantener una accion principal clara para comenzar y una accion secundaria para repetir.
- Dejar zonas seguras amplias para interaccion tactil.

## Paleta y accesibilidad

Base clara y calmada: azul petroleo suave, crema, azul cielo, amarillo calido, coral y verde menta. Usa contraste alto entre texto y fondo, pero no uses rojo y verde como unica diferencia de estado. La saturacion debe ser moderada y cada color debe tener una diferencia de luminosidad evidente.

## Restricciones

- Relacion de aspecto 16:10, composicion preparada para 1280x800.
- No incluir texto legible dentro de la imagen; todos los textos son placeholders visuales o deben omitirse.
- No incluir logotipos, marcas de agua ni elementos de interfaz de un editor.
- El mockup es una referencia visual, no un asset unico para importar en Unity.
- No dibujar controles como una sola ilustracion plana: sugerir piezas separables para panel, boton, icono, tablero y fondo.
- Mantener el fondo completo como referencia, pero separar mentalmente fondo, paneles y controles.

Entrega una unica imagen de referencia de alta resolucion, con jerarquia clara y suficiente espacio alrededor de los elementos.

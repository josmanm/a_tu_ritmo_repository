# Mockup B: rediseño intermedio de SimonScene

Genera un mockup de pantalla completa para el videojuego educativo infantil de ritmo y memoria musical "A tu Ritmo". Usa la captura actual adjunta de `Assets/Scenes/SimonScene.unity` como referencia funcional, no como estilo obligatorio. Si se adjuntan referencias adicionales, úsalas solo para forma, color y acabado.

## Objetivo

Conservar toda la funcionalidad pedagógica de Simon, pero reorganizar la pantalla alrededor de una familia visual coherente: tablero central, HUD compacto, feedback comprensible, controles grandes y estados interactivos claros.

## Direccion visual

Rediseño intermedio: lenguaje de formas basado en pildoras, tarjetas redondeadas y anillos de ritmo. Ilustracion 2D infantil contemporanea, geometrica y calida, con contornos suaves, sombras cortas y profundidad moderada. La interfaz debe transmitir ritmo mediante pulsos, anillos y bloques de compas, no mediante exceso de adornos.

## Composicion obligatoria

- Un panel de juego central dominante con el tablero Simon y cuatro zonas de color.
- Un encabezado superior unico que agrupe puntos, vidas, nivel o tiempo y menu sin competir con el tablero.
- Un modulo de instruccion central superior o superpuesto que muestre visualmente observar, escuchar, repetir y resultado; no depender solo del texto.
- Un boton principal de jugar y un boton de repetir visualmente diferenciados.
- Indicador de progreso y tiempo legibles desde distancia.
- Estados normal, resaltado, pulsado, deshabilitado, correcto e incorrecto claramente distinguibles.
- Espacio negativo suficiente; maximo un foco pedagogico principal simultaneo.

## Paleta

Azul noche suave para contraste, crema como superficie, turquesa, amarillo sol, coral y violeta como acentos. Los colores de las zonas deben ser estables entre estados. Usa cambios de luminosidad, escala y borde para estados; no uses solo color para comunicar aciertos o errores.

## Restricciones para Unity

- Relacion de aspecto 16:10 y referencia 1280x800.
- No colocar palabras, numeros, instrucciones ni letras dentro de botones o paneles generados; dejar areas limpias para TMP editable.
- No generar una pantalla destinada a usarse como una sola imagen en el juego.
- Diseñar visualmente piezas separables: fondo, tarjeta de panel, boton primario, boton secundario, iconos, tablero, barra y feedback.
- Fondo simple, sin detalles de alto contraste detras de los controles.

Entrega una imagen de mockup completa, centrada en la experiencia y no en una ilustracion decorativa.

# Simon button surfaces

Genera superficies 2D transparentes y reutilizables para los botones inferiores de Simon en "A tu Ritmo", usando el mockup maestro aprobado como referencia.

## Entrega

- boton primario ancho para JUGAR;
- boton secundario compacto para REPETIR;
- estados visuales normal, resaltado, pulsado y deshabilitado;
- una variante neutra de boton redondeado para futuras acciones.

## Restricciones

- Fondo transparente.
- No incluir texto, letras, numeros, simbolos, flechas, iconos, logotipos ni marcas de agua.
- Los iconos de jugar y repetir se añadiran en Unity o como assets independientes.
- Dejar el centro limpio para TextMesh Pro editable.
- Formas redondeadas, bordes suaves, sombras cortas y contraste suficiente.
- Piezas aptas para Sprite Mode y 9-slice.
- No incluir el tablero, HUD, fondo ni pantalla completa.
